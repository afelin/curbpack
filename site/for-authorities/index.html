For authorities, auditors, and CISOs

Local pack gates. Humans review. Not conformity assessment.

What it is

A local-first command-line tool that evaluates packs (JSON rule sets) against a git repository and writes structural evidence for human review. An instrument panel / evidence habit — not a full security program. Pair with software composition analysis (SCA) and secret scanners for depth.

What it is not

  • Not conformity assessment, CE marking, or notified-body approval.
  • Not a claim that green gates equal legal market access or Cyber Resilience Act (CRA) conformity.
  • Not governance-risk-compliance (GRC) SaaS, a cloud policy brain, or LLM-as-judge.
  • Not an official NCSC/FRA/agency product or endorsement.
  • Not dependent on any private tutor product to operate.

Institute neutrality

Development may be institute-supported. RISE is a funder / applied-research supporter — not this product’s certifier. Never “RISE-approved,” “NCSC-approved,” or agency-endorsed product claims. Repo: promotion firewall.

Air-gap / offline

Daily check needs no remote policy brain. Packs ship embedded; refresh via air-gap import or a sha256-pinned network update. Install verifies release checksums fail-closed.

Claim-safe boundaries

Safe: “prepares structural evidence for human review.” Unsafe: that CyberReady certified the product, completed conformity assessment, or that gate green equals CRA-compliant. This page is not certification theater.
