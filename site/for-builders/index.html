For builders

One first move. Under ten minutes to green. Open the browser only when you mean to.

First move — pick exactly one:

  1. Safe try: install → cyberready doctor → cyberready demo (prints a one-pager path; add --open only if you want the OS to open it).
  2. Product repo: cyberready init then cyberready check (defaults: house-policy + hooks + skill + ide).
  3. CI-only: drop the example workflow pinned @v0.4.2 with heal: true.

Before a review wave: prepare-release, then a human attest.

Agents: use the Cursor skill; never loop on demo to “show the page.” Link the static sample instead.

Recipes: repo docs/getting-started/60-second-paths.md. Packs: docs/write-your-own-pack.md.
