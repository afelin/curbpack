What it is / what it is not

Sixty seconds of clarity. Everything else is optional depth.

Is: a command-line tool that checks documentation and dependency rules from data packs, then writes review artifacts locally. Pilot pin @v0.4.3.

Is not: a conformity assessment, CE mark, notified-body opinion, or cloud compliance SaaS. Green gates mean ready for a human to look — not approved. Not a RISE or agency certification product.

Optional tutor: an airlocked explain-packet may go to any operator-chosen local chat. Tutors propose only — you must re-check; the packet never greenlights.
