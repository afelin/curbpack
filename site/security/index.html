Security model

What you can trust — and what unsigned does not mean.

  • Install: release downloads verify checksums.txt (sha256, fail-closed) in both install.sh and the GitHub Action.
  • Attest: unsigned capsules are labeled unsigned. Fake agent-bind tokens are never treated as verified signatures.
  • Socket: optional integrator IPC uses a private path (mode 0600), not a shared world-writable /tmp default. Fail-open if unused.
  • Packs online: network update requires a sha256 pin; otherwise stay offline / air-gap import.
  • Regex: pack patterns are length-capped and time-bounded to reduce ReDoS (regular expression denial-of-service) risk.

Full plain-language write-up in the repo: docs/security-model.md. Co-promotion / RISE-neutral language: docs/promotion-firewall.md. Report vulnerabilities via SECURITY.md.
